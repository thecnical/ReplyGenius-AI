# ReplyGenius AI - Privacy Policy

**Last Updated:** March 2026

## Overview

ReplyGenius AI is a browser extension that helps users generate AI-powered replies for various messaging platforms. This privacy policy explains how we collect, use, and protect your data.

## Data Collection & Usage

### What We Collect

- **Message Content:** When you use the extension to generate replies, the message content you input is sent to our AI service providers (OpenRouter/Bytez AI) to generate responses. This content is processed in real-time and is not stored on our servers.
- **Usage Statistics:** We collect anonymous usage statistics to improve our service (e.g., number of replies generated, preferred tones).
- **API Keys:** Your API keys are stored locally in your browser's secure storage and are never transmitted to our servers.

### How We Use Data

- **Generate Replies:** Your message content is used solely to generate AI-powered reply suggestions.
- **Improve Service:** Anonymous analytics help us understand usage patterns and improve the extension.
- **No Selling:** We do not sell, trade, or transfer your personal data to third parties.

## Data Storage & Security

- **Local Storage:** API keys and user preferences are stored locally in your browser using Chrome's secure storage API.
- **No Permanent Storage:** Message content is not permanently stored on any server.
- **Encryption:** All API communications use HTTPS encryption.

## Third-Party Services

Our extension uses the following third-party AI providers:
- **OpenRouter** (https://openrouter.ai) - Primary AI provider
- **Bytez AI** (https://bytez.ai) - Fallback AI provider

These providers have their own privacy policies. We recommend reviewing their policies.

## Permissions

The extension requires the following permissions:
- `storage` - To save your API keys and preferences
- `activeTab` - To access the current tab for generating replies
- `scripting` - To inject content scripts for platform detection

## Contact

If you have questions about this privacy policy, please contact us through the Chrome Web Store support channel.

## Changes to Policy

We may update this privacy policy from time to time. Any changes will be posted on this page.
